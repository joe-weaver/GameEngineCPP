提出したプログラムは、「Wave Function Collapse（WFC）」というヒューリスティックの実装です。WFCとは量子物理学 と似ているアイデアで、最初様々な状態が可能のピクセルを観測して、ひとつの状態を選んで、その状態を周りに再帰てきに広めます。普通にループごとに選んだのは最低なエントロピー最低にあるピクセルです。タイルマップや３Dスペースなどの実装も可能ですが、こちらの実装で、インプットイメージからローカル的に似ているアウトプットイメージを作ります。具体的に言うと、インプットイメージから全部の３x３核を取得し、どちらの核が隣接にあればいいかというマップを作ります。ピクセルの状態の可能性は、取得した核です。ループごとに、最低なエントロピーがあるピクセルを選んで、その様々な可能性の中にランダム的にひとつの状態を選んで、隣接マップによってその選択を隣のピクセルの可能性をアップデートして広めます。その結果、だんだんと見た目がインプットイメージと似ているイメージを作ります。
WFCを面白く表示するために、C++によってアプリを開発しました。ライブラリでは、OpenGLにつながるためにglad・GLFW・glmを使用しました。今回の焦点はUIではなく、WFCなので、Dear ImGuiというUIライブラリも使用しました。グラフィックス・軽いゲームエンジンの構造・WFCは自分で実装しました。「pini/」というディレクトリにあるファイルと「main.cpp」はオリジナルです。デモのために、様々なイメージも作って、アプリでインプットイメージとして選ぶことができます。

ビルドために：
cmake -S ./build/cmake -B ./build -DCMAKE_BUILD_TYPE=Development
make -C ../build
